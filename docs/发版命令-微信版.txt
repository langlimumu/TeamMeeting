Team Loop 发版命令（Windows / PowerShell）
════════════════════════════════════════

【0】新开一个 PowerShell 窗口，先进项目目录
cd D:\TeamMeeting-prod

【1】首次部署 / 启动正式服务（8000）
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\deploy.ps1 -Action StartProduction -HostAddress 0.0.0.0

【2】灰度发布（起 8001，主站不受影响）
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\deploy.ps1 -Action Gray -HostAddress 0.0.0.0
然后浏览器打开 http://127.0.0.1:8001/ 验证新功能、新接口

【3】上线（灰度切正式 8000）
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\deploy.ps1 -Action Promote -HostAddress 0.0.0.0
（切换瞬间有 1~3 秒中断）

【4】收尾：停掉灰度
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\deploy.ps1 -Action StopGray

【5】查看当前运行状态（进程 / 端口 / 版本）
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\deploy.ps1 -Action Status

【6】出问题：一键回滚到上一版
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\deploy.ps1 -Action Rollback -HostAddress 0.0.0.0

【7】只停服务
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\deploy.ps1 -Action StopProduction

访问地址
────────────────────────────
本机正式：http://127.0.0.1:8000/
本机灰度：http://127.0.0.1:8001/
同事访问：http://<本机IPv4>:8000/     （IPv4 用 ipconfig 查）

必须注意
────────────────────────────
1. 所有命令都要带 -HostAddress 0.0.0.0，否则 8000 只绑 127.0.0.1，同事访问不到。
   项目自带的 .bat 双击脚本没带这个参数，所以只能用上面命令行，别双击 .bat。
2. Promote 读取的是「本次命令」里的地址，也必须带 -HostAddress 0.0.0.0，漏了会把 8000
   绑回 127.0.0.1，局域网立刻断。
3. 现在默认不再强制 HTTPS，内网 HTTP 直接登录即可，不需要设置任何环境变量。
   若将来前面挂了 Nginx 终止 TLS，再显式设置 TEAM_LOOP_REQUIRE_HTTPS=1 和
   TEAM_LOOP_TRUST_PROXY=1。
4. 灰度是沙盒：在 8001 上建的测试数据（用户 / 会议 / 积分等），Promote 后不会进正式库，
   这是设计如此，不是丢数据。
5. 正式库固定是 项目\data\weekly_team.db；灰度期间同事在 8000 上的真实写入不会丢。
6. 首次务必先跑【1】，它会写入版本记录，后面的【3】【6】才有"上一版"可切、可退。
7. 首次开 8000/8001，Windows 防火墙弹窗要点「允许」。
